# Feishu to TeX - L0 骨架验证

飞书文档转 LaTeX 项目的 Chrome 插件原型。

## 安装测试

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `print` 目录（即仓库根目录）

## 使用

1. 打开任意飞书文档 (`*.feishu.cn/docx/*`)
2. 点击插件图标
3. 等待检测完成，点击「导出 .tex 文件」

## L0 能力

- 检测飞书文档页面
- 提取标题、段落、粗体、斜体、链接
- 提取有序/无序列表
- 提取代码块（保留语言标识）
- 生成可编译的 .tex 文件（ctexart 文档类）
- 通过 Chrome 下载 API 导出

## 已知限制（L1/L2 后续解决）

- 图片仅输出占位注释，不实际下载
- 不处理复杂表格
- 不处理公式
- DOM 解析依赖飞书页面结构，可能不稳定
- 未接入飞书开放 API
